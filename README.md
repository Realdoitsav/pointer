# Taskline

A small, fast to-do list that runs entirely in the browser. No build step, no dependencies, no account.

## Features

- Add, edit, complete, and delete tasks
- Filter by All, To do, or Done
- Progress bar that fills as you finish tasks
- Saves automatically in your browser (localStorage)
- Keyboard accessible, works on mobile, follows your light or dark system theme

## Run it

Open `index.html` in any modern browser.

## Host it on GitHub Pages

1. Push this folder to a GitHub repository.
2. In the repository, go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Your app will be live at `https://<your-username>.github.io/<repo-name>/`.
